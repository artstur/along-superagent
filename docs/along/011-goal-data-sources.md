# 按目标推荐数据源

主分类：agent / data；依赖 Along 客户端对应数据源卡片修复。基线 `b42bb7a5b571e1d6f6945f6528d41333aee27630`。

## 目标与验收

用户创建 OKX 交易复盘目标后，Agent 根据该目标推荐 OKX 数据源，App 展示推荐原因和前往 OKX 官方设置的入口；无关目标不再默认显示 Apple Health。入口打开不代表已授权或已连接。OKX OAuth 尚未申请，本轮不接账户、不收密钥、不读取真实资产、不交易。

## 实现契约

- `goalDetail.dataSources` 为数组，项为 `{provider: "okx" | "apple-health", status: "recommended", reason: string}`，reason 长度 1–240。模型不可提交 URL、密钥或 connected 状态；客户端/宿主可信目录决定名称和官方入口。
- 新增只读 `along_data_sources_catalog` 和宿主绑定写入 `along_data_sources_recommend`。推荐使用当前 `base_revision` / `input_version`，仅当前真实聊天所绑定的 active 目标可写；创建目标后可在同一工作内推荐，不能指定 user/goal。空数组撤回本目标的显式推荐。
- schema 8→9 新增目标推荐表，和业务库共用事务；同内容重试不加同步记录，变化追加现有目标同步项。冷启动、分页同步及重放均从持久事实投影。
- 健康域目标默认提供 Apple Health；custom 目标仅当 Agent 显式推荐或宿主已记录当前输入版本的相关健康类型时展示。无相关类型不推断健康数据源。
- 规划提示先识别目标所需数据、检查可用目录并推荐相关连接，再讨论导入备选；实际不支持的授权不能声称可用，不向手机用户暴露 Worker 目录。金融演示边界仅允许本轮公开接入说明和推荐；真实账户能力继续不启用。
